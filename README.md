# Manufacturing Payroll Analysis

## Project Overview
This project simulates a basic payroll process for a manufacturing company using fictional employee data.

## Objective
The objective of this project is to practice payroll calculation, employee data processing, payroll exception checking, and department-level payroll analysis using Microsoft Excel.

## Tools Used
- Microsoft Excel

## Excel Functions Used
- VLOOKUP
- IF
- IFERROR
- SUMIFS
- COUNTIFS

## Analysis Performed
- Combined employee master and attendance data
- Calculated basic salary, allowances, overtime pay, gross pay, and net pay
- Created payroll exception checks
- Summarized payroll costs by department
- Reviewed unusual payroll records before payment processing

## Workbook Structure
- Project Overview
- Employee Master
- Attendance
- Payroll Calculation & Analysis
- Department Summary

## Disclaimer
All employee data in this project is fictional. Payroll assumptions are simplified for learning and portfolio purposes and do not represent official Indonesian payroll regulations.
